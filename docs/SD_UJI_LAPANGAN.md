# Petualangan Ilmu SD — Daftar Uji Lapangan (orang tua & guru)

Dipakai saat anak mencoba game di HP (Tahap 9). Centang yang berjalan baik, catat yang tidak di kolom "Catatan".
Hasilnya dipakai untuk tahap revisi. Cukup 15–30 menit per anak; tidak perlu menyelesaikan semua pulau sekaligus.

## Sebelum mulai

- [ ] Launcher sudah memperbarui game ke versi **4.0.1** atau lebih baru (lihat di daftar game).
- [ ] Baterai HP cukup, volume suara nyala.
- [ ] Anak membuat profil sendiri: nama, **kelas yang benar**, pahlawan, baju.
