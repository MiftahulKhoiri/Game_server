# Klien Android (Godot 4)

Folder ini disiapkan untuk proyek Godot. **Belum dibuat**; langkah berikutnya
setelah server stabil.

Rencana:

1. Proyek Godot 4 (GDScript) dengan layar daftar/masuk, peta, dan HUD.
2. Berbicara dengan server memakai kontrak di [`docs/API.md`](../docs/API.md).
3. Alamat server dapat diatur di dalam aplikasi (IP Pi di Wi-Fi rumah, atau
   alamat tunnel bila bermain dari luar).
4. APK dibangun otomatis lewat GitHub Actions (Godot export), lalu diunduh
   dari halaman Releases dan dipasang di HP.
